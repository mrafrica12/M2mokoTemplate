# Asset library

- `logo/`: source profile mark for logo/reference use.
- `image/`: selected hero and editorial images.
- `shopping/`: product-oriented model photography, renamed descriptively.
- `gallery/`: untouched downloaded Instagram image files using source IDs.
- `css/`: starter brand color variables.
- `js/`: reserved for Shopify theme scripts.

The downloaded Instagram images are mostly 480–512 by 640 pixels. The WebP files use quality 82, preserve the source dimensions, and strip unnecessary metadata. The JPG originals have been removed. Higher-resolution originals should still be requested for the production store.
